# MiniMax H3：提示词与调用

## 必须有参考图

本技能中的 `minimax-h3` **仅支持参考图生视频，不支持纯文生视频**。每个请求必须提供 1–9 张图片，
本地图片通过 `--image` 编码，或提供公开可访问的图片 URL。视频/音频可作为额外参考，不能代替图片。
没有图片时先向用户获取；生成参考图也在已授权范围内时可先调用图片模型，然后使用其成品。
不要用空值、虚构 URL 或无关图片绕过约束。构造脚本和提交入口都会在联网前拒绝无图 H3 请求。

## 提示词准备

**每次使用 H3，必须在提交前先按 H3 专用规则优化提示词。** 先观察实际参考图片，明确主体、构图、
需保留的特征和目标动作，再在当前 Agent 内完成专用提示词。无须另外调用文本模型，也没有已知的
服务端优化接口或参数；请求构造器只校验和编码，不会替代这一步。
用户已有优化过的 H3 提示词时完成一致性检查并保留，无须重复改写；用户明确要求原样使用时尊重其要求。
所有规则均在本包内：

- 默认按 [参考格式](h3-reference.md) 优化，阅读其中的主体、素材标签、保留分析和分镜规则。
  使用六字段：`subject_definitions`、`summary`、`retention_analysis`、
  `detailed_description`、`overall_soundscape`、`non_diegetic_music`。
  JSON 文件中第一和第三项为字符串数组，其余为非空字符串；也可保存已排好的普通 UTF-8 文本。
- 表达首/尾帧意图或需要镜头/对白细节时参考 [基础格式](h3-base.md)。已有适用的三字段 H3 提示词
  可保留，但仍必须提供图片；基础资料中的 T2VA 只用于理解通用语法，不代表本 API 支持纯文生成。

提交前检查：素材标签都有真实输入，主体特征来自实际图片，保留/变化关系清楚，动作和台词能在指定时长内
完成，声音字段正确，提示词时长与请求参数一致。将优化结果保存为提示词文件，再运行 `prepare` / `submit`。

适配说明优先于通用模板：本包接受整数 **1–15 秒**，短片用一个可读动作和适量细节，
不要为凑 350–500 词而强塞多个镜头。原接口资料为 5–15 秒，1–4 秒源于用户配置要求，
服务端是否接受尚未实测。若被拒绝，报告限制而非擅自延长。
用户要求原样保留对白或标点时，覆盖通用参考中标点规范化的建议。

英文描述，台词/歌词/画面文字保留原语言。首镜头不加时间戳；后续镜头使用
`[Shot N] At MM:SS.mmm, ...`，时间递增且不超出总时长。维持身份、服装、道具、位置和动作状态连续。
声音分别描述现场声音与观众才能听见的音乐；不要重复整段对白。

`<Picture N>`、`<Video N>`、`<Audio N>` 按每类真实素材独立编号，不凭空引用素材。
构造器自动检查编号并在提交文本前添加与 `@图像N`、`@视频N`、`@音频N` 的绑定说明；
原始提示词文件不改动。此说明是客户端提示词文本，不是额外 API 字段。

**模式与保证不同**：通用指南可表达 I2VA/FL2VA/L2VA、编辑、续写意图；这个 FastAiApi 契约
只暴露 reference 角色，没有 `first_frame`、`last_frame`、`mode`。不能承诺硬性首尾帧锁定。

## 请求协议

接口固定为 `https://newapi.fastaiapi.cloud`，凭据使用 `--provider h3` 单独配置。
以下是本适配器发送的字段；本站渠道的参数兼容性尚未完成付费验证。

`POST /v1/videos`，模型 `minimax-h3`。请求字段仅有：
`model`, `content`, `resolution`, `ratio`, `duration`，可选 `metadata`（字符串键值）。
`content` 包含恰好一个 `{type: "text", text: "完整提示词"}`；六字段 JSON 被序列化进这个字符串。

| 参考类型 | 远程 URL 条目 | 本地编码条目 | role | 数量上限 |
| --- | --- | --- | --- | --- |
| 图片 | `image_url: {url: ...}` / `type: image_url` | `image_b64` / `type: image_b64` | `reference_image` | 9 |
| 视频 | `video_url: {url: ...}` / `type: video_url` | `video_b64` / `type: video_b64` | `reference_video` | 3 |
| 音频 | `audio_url: {url: ...}` / `type: audio_url` | `audio_b64` / `type: audio_b64` | `reference_audio` | 3 |

本地素材转 Data URL，URL 必须公开可访问；不自动上传用户文件。整体 JSON 不超过 10,000,000 字节。
分辨率**目前只支持 `720p`**，比例 `16:9` 或 `9:16`。`2k` 当前不可用，构造器会直接拒绝；
用户要求 2K 时说明暂不支持，用 720p 生成，需要更高分辨率时在后续制作中放大。
实际输出尺寸以本站返回文件为准，需要精确交付画布时检查后处理。

```bash
python3 <skill>/scripts/media_api.py prepare --model minimax-h3 \
  --prompt-file <project>/h3-prompt.json --duration 10 --ratio 9:16 --resolution 720p \
  --image <project>/character.png --run <project>/runs/h3-01
python3 <skill>/scripts/media_api.py submit --run <project>/runs/h3-01
python3 <skill>/scripts/media_api.py wait --run <project>/runs/h3-01 --timeout 50
python3 <skill>/scripts/media_api.py download --run <project>/runs/h3-01 --output <project>/h3.mp4
```

`--image` 至少一次。重复 `--image`、`--video`、`--audio` 可添加素材；视频和音频参考不能替代必需的图片。

## 幂等、查询与下载

准备时生成稳定 Idempotency-Key 并校验请求摘要，但不假定服务端提供幂等保障。
禁止自动重发提交或使用 --retry-ambiguous 恢复；结果未知时先在本站核对任务 ID，再 recover。

`GET /v1/videos/{id}` 约每 30 秒查询：`queued` / `dispatching` / `running` / `retrying`
继续等待，`succeeded` 成功，`failed` / `canceled` 终止。服务端 `retrying` 不表示客户端要重发。
下载实际返回的 `output_url`，不携带 FastAiApi Authorization，不猜测 URL，不在日志输出签名链接。
结果保留期限以本站实际策略为准，不沿用旧供应商期限。没有已验证的取消路由，不构造 DELETE。
