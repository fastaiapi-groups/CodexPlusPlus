日期：2026-11-05（Asia/Shanghai）。用户明确要求先开发和测试网页，不打开 App；本次未运行 relaunch/open，也未启动 GUI 实例。仅运行回环网页及 Rust CLI 接口桥。

## 实现

- 登录、注册页右上角依次为平台选择、路线选择；平台弹窗复用路线弹窗的深色、青绿色选中边框、图标与勾选样式，表单中不再放平台按钮。先选 New API 或 SubAPI。平台切换保留当前登录/注册模式，清除上一平台的表单、账号数据和组件状态。
- New API 原三条路线、共享会话和现有配置保持兼容；SubAPI 入口 https://fastaiapi.cloud，暂显示路线1。
- 请求显式携带平台身份；会话、记住的账号、媒体 Key、模型配置 ID 和上次模型选择分别存储。同编号 Key 不会碰撞。切换浏览平台不应用 Codex 配置，不改当前媒体环境；同平台换路线保持会话和页面状态。
- SubAPI 接入用户登录、注册、邮箱验证码、TOTP、Token 刷新、用户资料/余额、Key、分组、模型目录/价格、订阅、充值配置/套餐/订单及兑换。只使用用户接口，不使用管理员权限。
- SubAPI 注册使用邮箱认证，注册后更新用户名为邮箱前缀；更新失败提示，不误报整个注册失败。余额为 USD；价格由 per-token 转为 USD/百万 tokens，并计入对应分组用户倍率。
- 媒体描述按平台验证来源和凭据命名空间；异步任务只允许同后台换路线，不允许跨 New API/SubAPI 恢复。
- 网页桥不自动登录、不写 Codex 配置，充值和兑换写操作关闭。?fixture=1 为显式离线场景，不触达真实后台/系统环境，不保存测试密码。

## 后续调整：登录后固定平台

用户最新要求覆盖前文“登录期间随时切换平台”的历史行为：平台仅在未登录时可选。登录、注册成功或恢复已有有效会话后，右上角平台改为固定名称，取消按钮及下拉箭头；当前平台线路仍可选择。完成退出登录后才重新开放平台选择。

原生分发层同样固定当前认证平台，拒绝切换到另一平台以及对另一平台的账户/模型请求；认证与切换串行处理，避免进行中的认证被平台切换打断。TOTP 尚未验证完成时不计为登录成功。退出失败时维持固定状态，只有成功退出才解除限制。
